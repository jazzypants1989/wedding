How a name becomes music

Each letter of the signer’s name is a note. The letters run A to G, then start again: H is A, I is B, O is A again, and so on, so every name is a little phrase on the white keys. The words of the message set the rhythm: short words are quick, long words linger. Hearts end the phrase on a chord, and a favourite rings a bell.

The memory book prints every tune as sheet music, with the letters underneath as lyrics. Anyone can play it on a piano with one finger.
