Effects

Promote tuned effect values to every visitor. Open the effect studio, tune an effect, "Save to browser", then click "Import from this browser" below to pull those values in and save them site-wide. The stored override is a sparse { effectId: { key: value } } map (only changed keys); saving an empty map clears the override. Changes apply on the next page load — no redeploy.
